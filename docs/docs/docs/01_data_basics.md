# Data Basics

## Structured Data

Structured data has a fixed schema with rows and columns.

Example: shipment table with shipment_id, carrier, promised_date,
actual_date, and status.

## Semi-Structured Data

Semi-structured data has flexible structure, often stored as JSON.

Example: shipment tracking event containing shipment_id, event,
event_time, location, and optional remarks.

## Unstructured Data

Unstructured data has no predefined schema.

Example: delivery photo, customer complaint email, or PDF invoice.

## Why It Matters

A data engineer must choose the right storage and processing approach
based on the data type.

## Supply-Chain Examples

- Structured: shipments, orders, warehouses
- Semi-structured: carrier tracking events
- Unstructured: package photos and customer emails
